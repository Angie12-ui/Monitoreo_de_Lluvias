# Sistema de Monitoreo de Lluvia y Precipitación

App web (HTML, CSS y JavaScript) para registrar lluvia por zonas y compararla con el estándar de Cali (14 mm).

- Login: usuario `CVC`, contraseña `Lluvias`
- Clave de registro continuo: `CLIMA`
- Ajuste del 5.3% si la lluvia inicia entre 3:00 p.m. y 6:00 p.m.
- Gráfica de barras y foto de la zona

Para probar: abrir `index.html` en el navegador.
